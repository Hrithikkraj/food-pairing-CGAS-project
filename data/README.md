# Data Sources and Instructions

This directory houses raw, interim, external, and processed data for the Flavor-Nutrition Pairing project.

## Directory Structure
- `data/raw/`: **READ-ONLY**, never edit manually.
  - `data/raw/ahn/`: Ahn et al. (2011) flavor compound links and recipe files (`ingr_comp`, `scirep-cuisines-detail`).
  - `data/raw/usda/`: USDA FoodData Central SR Legacy (April 2018 CSV distribution):
    - `food.csv`
    - `nutrient.csv`
    - `food_nutrient.csv`
    - `food_category.csv`
- `data/interim/`: Intermediate parquet/csv files generated by stages S1 and S2.
- `data/external/`: Reviewed mapping files, specifically `matching_log.csv` (human-in-the-loop review of Ahn ingredient to USDA food matches).
- `data/processed/`:
  - `ingredient_table.csv`: Ingredient metadata, compound counts, 11 %DV values, and low/high flags.
  - `pair_table.csv`: Unordered ingredient pairs with $N_s$, size-controlled $N_s$, complementarity scores $C$, recipe co-occurrence, and category pairs.

## Download Links
1. **USDA SR Legacy (April 2018 CSV)**:
   - URL: [https://fdc.nal.usda.gov/download-datasets](https://fdc.nal.usda.gov/download-datasets)
   - Extract files (`food.csv`, `nutrient.csv`, `food_nutrient.csv`, `food_category.csv`) into `data/raw/usda/`.
2. **Ahn et al. (2011) Flavor Network Data**:
   - Source: Supplementary data from Ahn et al., *Scientific Reports* 2011 ("Flavor network and the principles of food pairing").
   - Place ingredient-compound relations and cuisine recipes into `data/raw/ahn/`.
